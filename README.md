# 🛡️ Shield Estoque

Sistema leve em Python e SQLite desenvolvido para resolver um problema real de inventário: rastrear peças, organizar localizações físicas e auditar divergências (*peças fantasmas*) para evitar erros na separação de pedidos.

## 🚀 Tecnologias Utilizadas
* **Python 3.14**
* **SQLite / SQL**
* **Git e GitHub**

## 📂 Estrutura do Projeto
* `schema.sql`: Estrutura inicial do banco de dados e tabelas.
* `main.py`: Script de inicialização da conexão com o banco.
* `banco.db`: Arquivo local do banco de dados SQLite.
